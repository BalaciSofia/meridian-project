# Reflection

**What turned out to be harder than expected?**

Scoping. I had more feature ideas than time, so most of the work was
deciding what to cut, not writing code.

**What would I do differently if I started over?**

Write tests and validation as I built each feature, instead of leaving both
for "later" and running out of time.

**What did I learn about myself as a developer?**

I default to building features before hardening them. Good for getting a
full app working fast, bad for test and validation coverage.
